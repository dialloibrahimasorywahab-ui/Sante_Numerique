# Shared

Point d'entrée des éléments UI réutilisables dans plusieurs features.

- `components/` : composants sans logique métier ni état applicatif
- `pipes/` : pipes de présentation
- `directives/` : directives de présentation et d’interaction
- `utils/` : fonctions utilitaires sans état métier

Les composants de mise en page sont regroupés dans `layout/`.
